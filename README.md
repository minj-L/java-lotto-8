# 로또

## 구현해야 할 기능 목록

### 0. 공통예외처리

- null 값이나 빈 값이 입력되면 안됨

### 1. 입력 기능

1.구입금액 입력

+ 구현 기능 목록
    +
        1. 구입 금액을 1000원으로 나누기
+ 예외처리 목록
    + 구입금액이 1000원으로 나누어 떨어지지 않으면 에러

2. 당첨번호 입력
    + 구현 기능 목록
        +
            1. 구분자(,)기준으로 당첨번호 split
    + 예외처리 목록
        +
            1. 중복된 번호가 입력되면 안됨
        +
            2. 1과 45 사이의 숫자가 입력되어야 함
3. 보너스번호 입력
    + 예외처리 목록
        + 11과 45 사이의 숫자가 입력되어야 함

### 2. 출력 기능

1. 구매한 로또 만큼 로또 번호 리스트 출력
2. 구매한 로또와 입력한 로또 번호를 비교해 몇 개의 로또가 맞았는지 확인
3. 로또 당첨금으로 얻은 수익률 계산
